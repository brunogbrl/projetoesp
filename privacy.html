Política de Privacidade

Aplicativo: Contador de Seguidores

Última atualização: 16 de Outubro de 2026

1. Visão Geral

Esta Política de Privacidade descreve como o aplicativo Contador de Seguidores utiliza dados do Instagram através da API oficial da Meta (Instagram Graph API).

2. Dados Coletados

Nosso aplicativo coleta estritamente informações públicas necessárias para o funcionamento do contador físico:

  • Nome de usuário público do Instagram (@).
  • Contagem pública de seguidores (followers_count).

O que NÃO coletamos: Nós não coletamos senhas, mensagens diretas (DMs), histórico de navegação, fotos privadas ou qualquer informação pessoal sensível.

3. Finalidade do Uso dos Dados

Os dados obtidos são utilizados exclusivamente para exibir o número de seguidores no display físico do dispositivo conectado (ESP8266 / TM1637) e na interface web de configuração local do usuário.

4. Compartilhamento de Dados

Nenhum dado é vendido, alugado ou compartilhado com terceiros ou anunciantes.

5. Exclusão de Dados

Para solicitar a remoção ou exclusão de qualquer dado em cache, acesse nossa Instrução de Exclusão de Dados ou desconecte o aplicativo nas configurações do seu Facebook/Instagram.

6. Contato

Para dúvidas sobre esta política, entre em contato através do e-mail do desenvolvedor cadastrado no Meta for Developers.
